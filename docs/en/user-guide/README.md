# User Guide — MD GitHub Navigator

Welcome to the **MD GitHub Navigator** user guide. This documentation helps you maximize the reading and technical navigation features across tablets (specifically optimized for eye-care anti-glare screens like the **TCL NXTPAPER 11 Plus**) and modern Android smartphones.

> [!NOTE]
> Each chapter in this guide includes **graphical diagrams, visual mockups, and screenshots** demonstrating step-by-step functionality for both tablet dual-pane mode and mobile single-pane drawer layouts.

---

## 📚 Guide Table of Contents

1. [Getting Started](getting-started.md) — System requirements, installation (Google Play & GitHub Releases), and initial setup walkthrough.
2. [Adding Repositories](adding-repositories.md) — Connecting GitHub repositories (OAuth Device Flow / PAT) and local folders via Storage Access Framework.
3. [Reading and Navigation](reading-navigation.md) — eReader reading canvas: progress tracking, zoomable diagrams, dual-pane TOC, and themes.
4. [Annotations and Bookmarks](annotations-bookmarks.md) — Text highlights, dog-ear reading bookmarks, inline notes, and Markdown export.
5. [Settings and Customization](settings.md) — Typography scaling, Scholar/Paper/Neon themes, and storage cache manager.
6. [Text-to-Speech (TTS)](text-to-speech.md) — Hands-free audio reading, syntax sanitization, and playback speed controls.
7. [Frequently Asked Questions (FAQ)](faq.md) — Common questions regarding privacy, offline storage, and performance.
