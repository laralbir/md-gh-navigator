# User Guide — MD GitHub Navigator

Welcome to the **MD GitHub Navigator** user guide. This documentation is crafted to help you make the most of the application on Android tablets (specifically optimized for eReader-grade reading on glare-free displays like the **TCL NXTPAPER 11 Plus**) as well as modern smartphones.

> [!NOTE]
> Every section in this guide features **graphical examples, visual diagrams, and interface screenshots** illustrating step-by-step usage in both tablet mode (two-pane split layout) and smartphone mode (slide-out drawer).

---

## 📚 Guide Contents

1. [Getting Started](getting-started.md) — System requirements, dual installation (Google Play & GitHub Releases), and first launch walkthrough with screenshots.
2. [Adding Repositories](adding-repositories.md) — Connecting GitHub repositories (public/private via OAuth Device Flow or PAT) and local storage directories (SAF).
3. [Reading & Navigation](reading-navigation.md) — eReader reading canvas: progress indicator, zoom controls, two-pane split layout (TOC + reading view), and theme switching (Scholar, Paper, Neon Dev).
4. [Annotations & Bookmarks](annotations-bookmarks.md) — Text highlighting, margin notes, and Markdown export.
5. [Settings & Customization](settings.md) — Typography preferences (Literata/Inter), font scaling, storage management, and selective offline caching.
6. [Text-to-Speech (TTS)](text-to-speech.md) — Background speech engine with Android downloadable voices and language selection.
7. [FAQ](faq.md) — Frequently asked questions and troubleshooting.
