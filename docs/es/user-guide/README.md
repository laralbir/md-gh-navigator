# Guía de Usuario — MD GitHub Navigator

Bienvenido a la guía de usuario de **MD GitHub Navigator**. Esta guía te ayudará a sacar el máximo provecho de la aplicación, tanto en tablets (diseñada especialmente para la experiencia de lectura eReader en pantallas anti-reflejo como la **TCL NXTPAPER 11 Plus**) como en smartphones Android.

> [!NOTE]
> Cada sección de esta guía incluye **ejemplos gráficos, diagramas visuales y capturas de pantalla** ilustrando el comportamiento paso a paso en modo tablet (vista dividida en dos paneles) y modo teléfono (menú desplegable).

---

## 📚 Contenido de la Guía

1. [Primeros Pasos](getting-started.md) — Requisitos, instalación (Google Play y GitHub Releases) y primer inicio con capturas.
2. [Añadir Repositorios](adding-repositories.md) — Conexión con GitHub (públicos/privados con token o Device Flow) y carpetas locales (SAF).
3. [Lectura y Navegación](reading-navigation.md) — Experiencia eReader: barra de progreso, control de zoom, vista dividida (TOC + documento) y selector de temas.
4. [Anotaciones y Marcadores](annotations-bookmarks.md) — Resaltado de texto, creación de notas al pie y exportación a Markdown.
5. [Ajustes y Personalización](settings.md) — Selector de tipografías (Literata/Inter), tamaño de fuente, gestión de almacenamiento y caché offline selectiva.
6. [Texto a Voz (TTS)](text-to-speech.md) — Lectura por voz en segundo plano con selección de motores e idiomas de Android.
7. [Preguntas Frecuentes (FAQ)](faq.md) — Resolución de dudas y problemas habituales.
